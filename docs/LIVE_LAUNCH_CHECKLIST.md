# Live launch checklist

Do not turn on Live mode merely because the screens look finished.

## Technical

- [ ] Fresh isolated Supabase project passed migrations, RLS tests and security advisors.
- [ ] Data API table grants checked; RLS enabled on every exposed table.
- [ ] Stripe test payment + signed webhook tested, then live keys installed server-side.
- [ ] Map tiles and directions key restricted to the app’s domains/bundle IDs.
- [ ] Real driver phone GPS test passed from pickup to delivery.
- [ ] Customer tracking only shows the assigned driver and stops on completion.
- [ ] Error monitoring contains no address, card, full GPS or access-token data.
- [ ] Backups, restore procedure, support contact and incident owner named.

## Operating rules

- [ ] Merchant agrees its menu, prices, opening times, delivery radius and allergen information.
- [ ] Clear collection, cancellation, refund and late-delivery rules exist.
- [ ] Driver arrangement, insurance and lawful work/tax position checked.
- [ ] Privacy notice explains location processing and retention.
- [ ] Terms, support contact and complaints route are in the app.
- [ ] First 10–25 orders have a named owner watching dispatch.

## Commercial first move

One nearby takeaway, one dependable driver and a tiny radius gives you a real chance of first revenue without needing a giant platform. Charge the clearly shown £1.00 + £0.29 on a handful of controlled deliveries, learn what actually breaks, then widen the circle.
